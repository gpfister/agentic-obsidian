# Agentic Obsidian Vault

Centralized knowledge base and session tracker for the **Agentic** workspace and its Google Antigravity plugins.

## Structure

- **`sessions/`**: Archived agent sessions generated by `scripts/sync_sessions.py`. Contains detailed trajectory, reasoning steps, tool usage, and attachments.
- **`plugins/`**: Documentation, specifications, and manifests for plugins built in this workspace (e.g., `gp-coding-plugin.md`).
- **`architecture/`**: Architecture decision records (ADRs), workspace diagrams, and Antigravity plugin conventions.
- **`templates/`**: Note templates for sessions, new plugins, and ADRs.
- **`references/`**: Official guidelines, Antigravity API references, and development tips.
