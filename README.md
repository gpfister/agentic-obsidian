# Agentic Obsidian Vault

Centralized knowledge base and session tracker for the **Agentic** workspace and its Google Antigravity plugins.

## Structure

- **`sessions/`**: Archived agent sessions generated by [`scripts/sync_sessions.py`](file:///Users/gpfister/Development/Projects/gpfister/agentic/scripts/sync_sessions.py). Contains detailed trajectory, reasoning steps, tool usage, and copied session artifacts under `sessions/attachments/<session-id>/`.
- **`features/`**: Feature specifications, requirements, and lifecycle tracking:
  - [`features/index.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/features/index.md): Master features catalog.
  - [`features/rename-plugin-repositories.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/features/rename-plugin-repositories.md): Synchronized rename of 5 plugin repositories to `<domain>-<gerund>-plugin` naming pattern.
  - [`features/project-grooming-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/features/project-grooming-plugin.md): Interactive project initialization, Matt Pocock style 7-category interrogation, and scaffolding coordination (`/project-grooming`).
  - [`features/agent-display-names-and-plugin-renames.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/features/agent-display-names-and-plugin-renames.md): Agent display names standardization (`Coding - ` prefix) and dual plugin repository rename (`agentic-task-monitoring-plugin`, `agentic-project-documenting-plugin`).
  - [`features/standardize-agent-handles.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/features/standardize-agent-handles.md): Standardize agent handles, aliases, skills, and directories to the `@coding-*` namespace.
- **`plugins/`**: Documentation, specifications, subagent catalogs, and lifecycle hook architectures for plugins built in this workspace:
  - [`plugins/index.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/index.md): Master plugins catalog.
  - [`plugins/agentic-coding-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-coding-plugin.md): Full specification of `agentic-coding-plugin` (`@coding` 6-stage pipeline: `@coding-clarify`, `@coding-specify`, `@coding-plan`, `@coding-develop`, `@coding-review`, `@coding-merge`).
  - [`plugins/agentic-issue-investigation-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-issue-investigation-plugin.md): Specification of `agentic-issue-investigation-plugin` (`@coding-investigate` autonomous root-cause investigator).
  - [`plugins/agentic-project-documenting-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-project-documenting-plugin.md): Specification of `agentic-project-documenting-plugin` (`@coding-document` documentation specialist).
  - [`plugins/agentic-project-grooming-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-project-grooming-plugin.md): Specification of `agentic-project-grooming-plugin` (`/project-grooming` interactive scoping and scaffolding coordinator).
  - [`plugins/agentic-prompt-triage-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-prompt-triage-plugin.md): Specification of `agentic-prompt-triage-plugin` (System 1 Laya Router prompt classifier).
  - [`plugins/agentic-task-monitoring-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-task-monitoring-plugin.md): Specification of `agentic-task-monitoring-plugin` (`@coding-monitor` telemetry and log surveillance).
  - [`plugins/agentic-topic-researching-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/plugins/agentic-topic-researching-plugin.md): Specification of `agentic-topic-researching-plugin` (`@coding-research` web research, topic investigation, and knowledge synthesis).
- **`research/`**: Research knowledge base indexed by topic and request:
  - [`research/index.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/research/index.md): Master research index, topic taxonomy, and request log table.
  - `research/topics/`: Long-term thematic knowledge syntheses.
  - `research/requests/`: Point-in-time research request deliverables and inquiry snapshots.
- **`architecture/`**: Architecture decision records (ADRs), workspace diagrams, and Antigravity plugin conventions:
  - [`architecture/overview.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/overview.md): Multi-repo workspace principles and repository map.
  - [`architecture/plugin-standards.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/plugin-standards.md): Directory conventions, manifest schema, declarative subagents, skills, and hooks.
  - [`architecture/worktrees.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/worktrees.md): Parallel session isolation using Git worktrees.
  - [`architecture/adr-001-standardize-agent-handles.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/adr-001-standardize-agent-handles.md): Standardize subagent handles, aliases, and skill identifiers to `coding-` namespace.
  - [`architecture/adr-002-agent-display-names-and-plugin-renames.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/adr-002-agent-display-names-and-plugin-renames.md): Agent display names standardization (`Coding - ` prefix) and dual plugin repository rename.
  - [`architecture/adr-003-project-grooming-plugin.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/adr-003-project-grooming-plugin.md): Project grooming architecture, skill-only execution, grilling protocol, interactive approval gate, and cross-plugin delegation.
  - [`architecture/adr-004-standardize-plugin-repository-names.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/architecture/adr-004-standardize-plugin-repository-names.md): Standardize plugin repository names across the ecosystem to `<noun/domain>-<gerund>-plugin` convention.
- **`templates/`**: Note templates for sessions ([`session-template.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/templates/session-template.md)), new plugins ([`plugin-template.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/templates/plugin-template.md)), and ADRs ([`adr-template.md`](file:///Users/gpfister/Development/Projects/gpfister/agentic/agentic-obsidian/templates/adr-template.md)).
- **`references/`**: Official guidelines, Antigravity API references, and development tips.
